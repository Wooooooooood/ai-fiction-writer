# 场景微逻辑卡模板

## 元信息

```markdown
---
scene: {scene-01}
chapter: {NN}
location: {精确地点}
start_time: {HH:MM}
end_time: {HH:MM}
characters_present:
  - {角色A}: {位置}，{状态}，{知道什么}，{想要什么}
  - {角色B}: {位置}，{状态}，{知道什么}，{想要什么}
---
```

## 进入状态

- 时间：{时刻}
- 地点：{精确位置}
- 上一场景结束状态：{简述}
- 每个人此刻知道什么：
  - {角色A}：{信息1}、{信息2}
  - {角色B}：{信息1}
- 每个人此刻不知道什么：
  - {角色A}：{信息3}
  - {角色B}：{信息2}、{信息3}

## 动作链

### 动作 1：触发

- 谁做了什么：{角色A} {动作}
- 时间过了：{多久}
- 地点变化：{无 / 从A到B}
- 信息变化：{无 / 角色B知道了X}
- 动作前四问：
  - 谁在场？{答案}
  - 他们刚在哪？{答案}
  - 为什么要这么做？{答案}
  - 信息/道具来源？{答案}
- 判定：{通过 / 不通过}

### 动作 2：反应

- 谁做了什么：{角色B} {反应}
- 时间过了：{多久}
- 地点变化：{无 / 从A到B}
- 信息变化：{无 / 角色A知道了Y}
- 动作前四问：{通过 / 不通过 + 简述}

### 动作 3：结果

- 谁做了什么：{角色A} {决定}
- 时间过了：{多久}
- 地点变化：{无 / 从A到B}
- 信息变化：{无 / 双方都知道了Z}
- 动作前四问：{通过 / 不通过 + 简述}

## 退出状态

- 时间：{时刻}
- 地点：{是否变化}
- 在场人物及位置：
  - {角色A}：{位置}
  - {角色B}：{位置}
- 每个人知道什么 / 不知道什么（更新后）：
  - {角色A}：知道{...}，不知道{...}
  - {角色B}：知道{...}，不知道{...}
- 留下的悬念/钩子：{描述}
- 下一场景衔接点：{描述}
