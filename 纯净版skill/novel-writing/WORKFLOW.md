# Novel Writing 实操流程（通用版）

> 本文件是 `SKILL.md` 的落地执行版。每次撰写新章节前，Agent 必须按此清单执行，完成后按此清单汇报。

---

## 第一步：读上下文（写前强制）

### 1.1 读取前 10 章切片

路径：`.novel/progress/slices/`

- [ ] 读取 `ch{N-10}_slice.md` 到 `ch{N-1}_slice.md`
- [ ] 若切片缺失，补读对应章节正文
- [ ] 重点记录：人物状态变化、物质细节、情感线进展、活跃伏笔
- [ ] **记录每章关键时间节点**（如"06:40 起床""11:45 会议结束"）

### 1.2 精读前 5 章正文

路径：`chapters/vol{N}-{卷名}/`

- [ ] 读取 `ch{N-5}.md` 到 `ch{N-1}.md` 全文
- [ ] 核对：**时间衔接**（上一章结束时刻 → 本章起始时刻）
- [ ] 核对：地点一致性、服装/外貌连续性、情感曲线
- [ ] 标记与当前细纲冲突的细节，尤其是时间矛盾

### 1.3 读取当前章细纲与卷大纲

- [ ] `.novel/outline/细纲/ch{NN}-细纲.md`
- [ ] `.novel/outline/outline.md`
- [ ] 冲突项必须先与作者确认，不得擅自吃书

### 1.4 读取世界观设定

路径：`.novel/worldbuilding/`

- [ ] 读取 `worldbuilding/world.md` 世界总览
- [ ] 读取当前地点的地图档案（L1/L2/L3）
- [ ] 读取 `worldbuilding/timeline/calendar.md` 历法
- [ ] 读取出场角色所属势力档案
- [ ] 读取相关规则体系与文化禁忌
- [ ] 冲突项必须先与作者确认

### 1.5 读取角色/知识/追踪/进度

- [ ] 出场角色档案：`.novel/characters/{角色名}.md` 和 `.novel/characters/new/{角色名}.md`
- [ ] 知识库：`.novel/knowledge/`
- [ ] 追踪文件：`.novel/tracking/上下文.md`、`.novel/tracking/伏笔.md`、`.novel/tracking/时间线.md`、`.novel/tracking/角色状态.md`
- [ ] 进度：`.novel/progress/progress.json`

---

## 第二步：写逻辑骨架

- [ ] 已创建/更新逻辑骨架文档（可暂存在对话中或独立文件）
- [ ] 每个场景包含：**触发、反应、结果**
- [ ] 已做主角边界检查
- [ ] 已做专业人员各司其职检查
- [ ] 已确认无世界观/感情线阶段越界
- [ ] 已确认地点/势力/规则与世界building一致
- [ ] **作者已确认骨架**

---

## 第三步：写细纲

- [ ] 已创建/更新 `.novel/outline/细纲/ch{NN}-细纲.md`
- [ ] 每个场景包含：**时间、地点、角色、目标、冲突、结果、情绪**
- [ ] 包含：对话要点、关键描写、爽点设计、钩子设计、情感曲线
- [ ] 时间线已与 `.novel/tracking/时间线.md` 核对，无倒流或异常跳跃
- [ ] **作者已确认细纲**

---

## 第四步：写正文

- [ ] 严格按细纲节拍推进，不擅自增删核心场景
- [ ] 字数达标
- [ ] 每章至少 1 个爽点
- [ ] 章尾必须有钩子
- [ ] 多线推进，不连续 3 章单线
- [ ] 无时代错位词、无情感直给、无模板化表达
- [ ] 角色无 OOC
- [ ] 时间线清晰，上下午转换有明确标记
- [ ] 无后台策划数字直接进正文
- [ ] 新增配角同步建档到 `.novel/characters/new/`
- [ ] 新增地点/势力/规则同步建档到 `.novel/worldbuilding/`
- [ ] 地理移动与地图设定一致

---

## 第五步：逻辑扫描

- [ ] 人物能力边界扫描通过
- [ ] 专业人员各司其职扫描通过
- [ ] 现实常识扫描通过
- [ ] 前后章因果扫描通过
- [ ] 世界观设定校验通过
- [ ] 地理移动合理性校验通过
- [ ] 势力/种族/职业设定校验通过
- [ ] 感情线阶段校验通过

---

## 第六步：严格质检

### 6.1 上下文一致性复核（自查）

- [ ] 与前 5 章正文人物状态、情感进展连续
- [ ] 物质细节与切片记录一致
- [ ] 已回收前章钩子/伏笔
- [ ] 按细纲节拍推进，无核心偏离
- [ ] 多线结构符合要求
- [ ] 时间线连续，本章起始时刻与上一章结束时刻衔接正确
- [ ] 时间展示自然，无后台时间线直给
- [ ] 人物关系、家庭称呼、作息时间、通话时间合理
- [ ] 关键信息有铺垫，人物知情有交代
- [ ] 新增配角档案已建档
- [ ] 新增地点/势力/规则档案已建档
- [ ] 世界观一致，无地理/势力/规则冲突

### 6.2 novel-humanizer 质检

- [ ] AI味检测通过
- [ ] 时代错位检测通过
- [ ] 角色OOC检测通过
- [ ] 世界观一致性检测通过
- [ ] 文学性评分 ≥ 75
- [ ] 逻辑性评分 ≥ 85
- [ ] 世界观一致性评分 ≥ 85
- [ ] 总分 ≥ 85

### 6.3 novel-review 审稿

- [ ] 编辑视角评分 ≥ 85
- [ ] 读者视角评分 ≥ 85
- [ ] 平台视角评分 ≥ 85
- [ ] 作者视角评分 ≥ 85（含时间线逻辑、世界观一致性）
- [ ] 无 P0 致命问题
- [ ] 总分 ≥ 85

---

## 第七步：修改定稿

- [ ] P0 问题全部修复
- [ ] P1 问题原则上全部修复
- [ ] P2 问题记录未处理项
- [ ] 修改后重新执行第五步逻辑扫描 + 第六步完整质检
- [ ] 更新 `.novel/progress/progress.json` 状态
- [ ] 生成/更新 `.novel/progress/slices/ch{NN}_slice.md`
- [ ] 生成/确认 `worldbuilding/map/map-update-suggestion.md`（如有新地点）

---

## 第八步：最终输出

输出时必须包含：

1. **正文路径**：`chapters/vol{N}-{卷名}/ch{NN}-{标题}.md`
2. **字数统计**：中文字数 / 总字符数
3. **质检摘要**：humanizer 总分 / review 总分 / 关键问题
4. **伏笔/钩子**：本章新增及回收情况，下章回收计划
5. **地图/设定更新**：本章新增/升级的地点、势力、规则
6. **下章建议**：基于本章结尾的推进方向

---

## 禁止行为

- ❌ 不读切片直接写
- ❌ 不读前 5 章正文直接写
- ❌ 不看细纲自由发挥
- ❌ 不核对时间线直接写
- ❌ 新增配角不建档
- ❌ 新增地点/势力/规则不建档
- ❌ 不查世界设定直接写
- ❌ 质检未通过直接输出
- ❌ 发现与正文冲突不报告、不修正
- ❌ 只给文字建议不执行工具
