# 文风学习指南

> 通用的文风定位、混合、执行与自检方法。
> 与《拆文方法论》配套：拆文负责"这本书怎么写的"，本指南负责"我要写成什么样"。
> 所有句法模板均为**模式占位符**，使用时替换为自己作品的内容，不照搬任何对标书原句。

---

## 一、文风定位方法

### 1.1 定位四要素

为每部对标书（及自己的作品）建立文风坐标：

| 要素 | 说明 | 示例写法 |
|------|------|----------|
| 核心气质 | 4～6 个关键词概括整体味道 | 如"质朴沉郁、执念深重" |
| 风格标签 | 题材类别标签组合 | 凡人流 / 热血逆袭流 / 克系诡异流 / 逍遥悟道流…… |
| 擅长场景 | 该文风最值得借鉴的场景类型 | 开篇定调、大场面、日常群像、恐怖氛围…… |
| 情绪曲线 | 张弛周期与爆发方式 | 慢热压抑后爆发 / 高频反转 / 舒缓中顿悟 |

### 1.2 文风档案模板

```markdown
# 文风档案：《{对标书名}》

## 定位
- 核心气质：{关键词}
- 风格标签：{题材标签}
- 一句话定位：{这本书的"味道"是什么}

## 量化特征
- 句长分布：短（<15字）{A}% / 中（15-30字）{B}% / 长（>30字）{C}%
- 对话占比：{区间}
- 标点习惯：{感叹号/省略号/破折号的频率与用途}
- 张弛周期：约 {N} 章一循环

## 声口特征
- 主角说话方式：{}
- 对话标签偏好：{高频标签}
- 潜台词密度：{高/中/低}

## 描写侧重
- 五感侧重：{视觉为主 / 听觉触觉优先 / 肮脏真实系……}
- 白描 vs 渲染：{比例}
- 心理外化方式：{动作暗示 / 直接独白 / 环境烘托}

## 标志性句式模式
1. {模式，占位符表示}
2. ……（5～10 条）

## 借鉴边界
- 值得学：{}
- 不适合学/需警惕：{}
```

### 1.3 分题材风格偏好参考

不同题材方向有各自的"默认文风配置"，定位时先对齐再微调：

| 题材方向 | 句长偏好 | 对话特征 | 情绪节奏 | 核心爽点 |
|----------|----------|----------|----------|----------|
| 热血逆袭 | 短句多、感叹号多 | 直接、霸气、带少年意气 | 快、外放 | 打脸、突破、身份揭露 |
| 凡人流 | 中句为主、稳 | 克制、功能性强 | 慢热、压抑后爆发 | 扮猪吃虎、谨慎逆袭 |
| 轻松搞笑 | 短句多、口语化 | 吐槽、现代梗、反套路 | 轻快、反转快 | 吐槽反转、身份错位 |
| 科学/知识修仙 | 长句多、逻辑推导 | 理性讨论、辩论式 | 偏慢热、认知突破爽 | 知识破解、成果发表 |
| 群像史诗 | 长短交替、有气势 | 潜台词多、宣言式 | 高低起伏、情绪叠加 | 群像高光、时代变革 |
| 儒家哲理 | 长句铺陈、古语感 | 藏锋、论道、机锋 | 慢热、厚积薄发 | 以理服人、顿悟 |
| 克系民俗诡异 | 短句破碎、口语粗粝 | 咒骂、真假难辨、自言自语 | 压抑-崩溃-爆发、高压快切 | 认知颠覆、死里逃生 |
| 逍遥悟道/古典仙侠 | 中长句为主、有古意 | 从容淡然、点化、人味浓 | 舒缓-顿悟-升华 | 一念悟道、高人风范 |
| 儒道仙武/王朝争霸 | 长句说明+短句宣言交替 | 论道、宣言、藏锋 | 3～5 章一循环，文武双爆发 | 文名震动、宏愿升华 |
| 高武乱世/群雄逐鹿 | 短句凌厉+长句铺陈战事 | 军令、宣言、论势、唱和 | 2～4 章一循环，战争与情感交织 | 收服、民心、大胜 |
| 悬疑探案 | 中短句、节奏明快 | 推理对白、内心吐槽 | 案件单元循环 | 破案反转、身份揭露 |

## 二、混合文风公式

### 2.1 通用结构

混合文风 = **骨架风格**（决定节奏与爽点结构）+ **血肉风格**（决定质感与厚度）+ **调味风格**（少量，提供差异化记忆点）。

- 骨架选 1 种，占比最高；血肉 1～2 种；调味不超过 1 种。
- 配比参考：骨架 50～70%，血肉 20～40%，调味 ≤10%。
- 混搭原则：核心风格保持一致，调味只在缓冲章、日常章释放，生死关头收束。

**配比记录格式**：

```
目标风格：热血 __% 轻松 __% 理性 __% 哲理 __% 诡异/逍遥 __%
骨架来源：{题材标签}   血肉来源：{题材标签}   调味来源：{题材标签}
```

### 2.2 开篇公式

**目标**：第一章内建立"强冲突 + 强反差 + 强悬念"。

- **强冲突**：主角面临生死、羞辱、追杀或重大危机。
- **强反差**：身份、能力、认知上的落差（天才变废柴、现代人入古代、普通人入超凡世界）。
- **强悬念**：给出一个必须被追问的问题（我是谁？这是什么世界？如何活下去？）。
- 变体：真假错位（读者与主角一起怀疑现实）、古今错位（现代细节反衬古典世界）、亲情缺失驱动（个人逆袭绑定家族/时代格局）、极端事件蜕变（一次危机完成心性转变）。

**推荐结构**：
1. 第一句/第一段定氛围。
2. 第一章内上危机，不拖泥带水。
3. 第二章开始揭示世界规则的冰山一角。
4. 前五章内完成第一次小爽点释放。

### 2.3 节奏公式

- **张弛周期**：3～5 章一循环为基准（快节奏 2～4 章，慢热 5～8 章）：
  - 1～2 章紧张推进（危机、战斗、揭秘）→ 1 章缓冲（日常、修炼、情感）→ 1 章铺垫升级 → 1 章小高潮释放。
- **爽点密度**：平均每章 1 个左右，关键卷可提升到 1.5～2 个。
- **大高潮**：每 20～40 章一个阶段性大高潮。
- 诡异高压线每 2～4 章需要一个喘息锚点；悟道舒缓线每 3～6 章需要一个顿悟升华点。

### 2.4 文笔公式

- **句长基准**：短句 30% / 中句 45% / 长句 25%。
  - 诡异紧张向：短句可升至 45%；古典意境向：长句可升至 40%；稳健叙事向：中句可升至 55%。
- **段落**：手机阅读导向，每段不超过 3～4 行，对话段更短；战斗用短段落制造紧迫感。
- **五感侧重**：热血线重视觉听觉；诡异线重嗅觉触觉等生理刺激；悟道线重听觉、触觉、雨声茶香。

### 2.5 人物公式

- **主角**：坚韧 + 理性 + 一点少年意气为基准，可叠加从容淡泊或偏执癫狂变体；设计一句口头禅或标志性自称作为声音标签。
- **核心配角（3～5 人）**：每人一个鲜明标签 + 一个独立信念 + 至少一次不依附主角的高光；可加入有灵性的小物件/小生灵作为叙事伙伴。
- **反派**：与主角在理念、利益、立场上冲突，而非单纯坏；可设置反派内部分歧增加博弈深度。

### 2.6 爽点公式

| 爽点类型 | 参考占比 | 说明 |
|----------|----------|------|
| 逆袭打脸 / 以弱胜强 | 15～20% | 轻视→试探→震惊→反杀 |
| 知识破解 / 认知突破 | 15～20% | 用逻辑/知识/技艺破解困境 |
| 身份揭露 / 马甲掉落 | 10～15% | 多重身份在关键时刻曝光 |
| 境界突破 / 获得宝物 | 10～15% | 升级仪式感 |
| 伙伴互动 / 师门情谊 | 10～15% | 群像高光、情感锚点 |
| 认知颠覆 / 死里逃生 | 5～10% | 诡异向专属 |
| 悟道点化 / 高人风范 | 5～10% | 古典向专属 |
| 复仇清算 / 情感执念 | 5% | 前期压迫后期回收 |
| 收服归心 / 民心凝聚 | 5% | 争霸向专属，落到具体事件 |

- 释放节奏：小爽点每 1～3 章，中爽点每 10～15 章，大爽点每 30～50 章。
- 大高潮尽量叠加多个爽点；释放前要有足够的压抑或期待铺垫。

## 三、写作纪律清单

### 必须做

1. **每章必须有推进**：信息、情绪、关系、实力，至少推进一项。
2. **章尾留钩子**：悬念、危机、发现、反转，给读者追更理由。
3. **用剧情带设定**：设定说明不超过三段，穿插在冲突与行动中。
4. **保持主角声音一致**：理性时理性，热血时热血，从容时从容，不人格分裂。
5. **给配角独立弧光**：核心配角至少有一次不依附主角的高光。
6. **控制理论/说明篇幅**：推导与说明用"问题解决"场景承载。
7. **战斗服务于人物与剧情**：每一场战斗都改变一点关系或局势。
8. **情感克制但有迹可循**：大悲大喜用动作和环境暗示，不空喊口号。
9. **真假/双世界叙事需有锚点**：用物件、疼痛、他人反应提示"哪边是真的"。
10. **保留人间烟火气**：再宏大的设定也要有柴米油盐、生老病死托底。

### 不要做

1. 不要开篇大段倾倒设定。
2. 不要让反派只会"废物""蝼蚁"式叫嚣。
3. 不要让主角在关键决策时智商掉线。
4. 不要让女性角色除了颜值和辅助外毫无记忆点。
5. 不要让战斗变成纯粹的光波对轰，缺乏战术变化。
6. 不要让轻松搞笑桥段在生死关头抢戏。
7. 不要让伏笔只埋不收，或收得太随意。
8. 不要让世界观后期无限制膨胀，提前设定天花板。
9. 不要让诡异元素沦为猎奇堆砌，需有基础规则支撑。
10. 不要让"以理服人"变成说教嘴炮，对手不能降智。

## 四、句法与表达规范

### 4.1 句长配比

```
短句（<15字）：30%   —— 开篇、战斗、情绪爆发、宣言
中句（15-30字）：45% —— 常规叙述、对话
长句（>30字）：25%   —— 设定解释、场面渲染、心理分析、悟道感受
```

按风格微调：诡异紧张向短句升至 45%（句子破碎口语化）；古典意境向长句升至 40%（承载意境与顿悟）；稳健技术流向中句升至 55%（保证清晰）；争霸史诗向长短交替（长句铺陈、短句宣言）。

### 4.2 对话标签库

| 情绪 | 标签 |
|------|------|
| 平静 | 说道、回道、轻声道 |
| 冷淡 | 冷声道、沉声道、淡淡道 |
| 愤怒 | 厉喝道、怒道、喝道、咆哮道 |
| 嘲讽 | 冷笑道、嗤笑道、讥讽道 |
| 开心 | 笑道、微笑道、哈哈大笑 |
| 紧张 | 颤声道、低声道、忙道、惊道 |
| 吐槽 | 吐槽道、干笑道、小声说道 |
| 从容 | 淡然道、缓声道、悠然道、喃喃道 |
| 癫狂 | 嘶吼道、癫笑道、咬牙切齿道 |
| 论道 | 沉声道、淡淡道、朗声道 |

### 4.3 高频表达分类框架

高频表达库按**使用场景**分类建档，每类只记模式（占位符）与写法说明，不存原句：

| 类别 | 用途 | 模式示例 | 写法要点 |
|------|------|----------|----------|
| 开篇定调 | 第一段建立氛围/格局 | "XXXX，别XXXX。" | 极简短句 + 环境细节 + 规则悬念 |
| 危机定调 | 开局上危机 | "{感官细节}。" | 感官先行，危机紧随其后 |
| 反差定调 | 天才变废柴等落差 | "{测试结果/身份宣告}。" | 数据化/仪式感宣告落差 |
| 错位定调 | 穿越/真假错位 | "{误判}……{真相}！" | 认知颠覆 + 现实锚点 |
| 过渡衔接 | 场景/情绪切换 | "{角色}{动作}，{神态}。" | 用动作和神态完成转场 |
| 战斗推进 | 打斗节奏 | "轰的一声。{招式}。" | 拟声词独立成句，招式具象 |
| 震惊/反转 | 爽点释放瞬间 | "全场寂静。"/"这怎么可能？！" | 短句收束，群像反应衬托 |
| 宣言收束 | 高潮落点 | "我必……"/"{四字短语}！" | 为主角设计标志性口号 |
| 五感描写 | 画面感与代入 | 按视/听/嗅/触/味分栏 | 每条模板注明适用氛围 |
| 心理外化 | 情绪不直给 | ❌"他很愤怒。" → ✅"{攥紧、指节泛白等动作}" | 用动作、神态、环境替代情感标签 |

**建档与使用方法**：
1. 拆文时按上表类别归档句式模式，每类 3～5 条，用占位符脱敏。
2. 写正文前根据本章场景（开篇/战斗/反转/收束）调用对应类别的模式。
3. 模式是节奏骨架，词汇必须换成自己作品的世界观语言。
4. 新增对标书时，只补充"该风格独有的类别"和"新的模式变体"，不重复存量。

## 五、风格自检清单

每完成一章，对照自检：

- [ ] 本章是否推进了信息、情绪、关系或实力中的至少一项？
- [ ] 章尾是否留下让读者想点开下一章的钩子？
- [ ] 是否有至少一处让读者感到"爽"或"有趣"的设计？
- [ ] 主角行为是否符合其核心人设（含所选变体）？
- [ ] 是否有大段说明文？若有，能否用剧情或对话替代？
- [ ] 对话是否符合说话者的身份和情绪？
- [ ] 环境描写是否服务于氛围或剧情，而非纯装饰？
- [ ] 是否有至少一个具体细节（五感或动作）增强代入感？
- [ ] 诡异/真假元素是否有锚点，避免读者迷失？
- [ ] 群像戏份中是否有配角获得独立表达空间？
- [ ] 伏笔是否有回收计划？
- [ ] 句长配比是否符合本章场景定位（战斗短、渲染长）？
- [ ] 是否存在 AI 味表达（时代错位词、系统面板腔、数据罗列、情感标签化、空泛感慨）？

**写作前快速注入卡**：

```

- 风格配比：热血__% 轻松__% 理性__% 哲理__% 诡异/逍遥__%
- 本章节拍：进入 → 冲突 → 转折 → 退出
- 出场角色：__________
- 核心爽点：__________
- 章尾钩子：__________
```

## 六、文风知识库的积累与更新

### 6.1 新增对标书的提取步骤

1. **采样**：取开头、中部、结尾三段样本（各 400～600 行），覆盖日常、战斗、对话、心理、设定说明及该风格特殊场景。
2. **维度分析**：按 1.2 文风档案模板逐项填写。
3. **提炼模式**：提取 5～10 个高频句式模式（脱敏为占位符），归入第四章分类框架。
4. **更新定位表**：若该书开创了新题材方向，在 1.3 分题材偏好表中新增一行；否则只更新既有行的参照。

### 6.2 更新触发条件

- 新增一部对标书并完成拆文。
- 发现生成文本存在明显风格偏差。
- 确定了具体创作方向，需要强化某类风格配比。
- 写作中发现新的高频表达模式或避坑点。

### 6.3 最小化更新原则

- 每次更新只修改或新增必要的条目。
- 不轻易推翻已有共识，除非新资料提供了更强证据。
- 保留变更记录，便于追溯风格定位的演变。
