# 拆文方法论

> 通用的对标书拆解方法论：拆解维度、拆解流程、横向对比、套路提炼与全套记录模板。
> 适用玄幻仙侠类长篇网文，其他网文类型可参照调整。
>
> **使用原则**：不复制，只提炼结构；不编造，只基于文本归纳；可组合，但混搭时保持核心风格一致。

---

## 一、拆解目标

1. **建立拆解标准**：统一从哪些维度分析小说，避免泛泛而谈。
2. **提炼套路模板**：每部作品总结出可迁移的桥段、结构、节奏模式。
3. **标注风险雷区**：汇总该风格下的常见失败模式与避坑提醒。
4. **形成横向参照**：多书对比，确认自己的定位与差异化空间。
5. **沉淀个人模块库**：拆文成果入库，供设定、大纲、日更各阶段调用。

---

## 二、八维拆解框架

统一使用以下八个维度拆解每部作品。每个维度配一组拆解问题，逐项作答，避免遗漏。

### 2.1 核心设定

| 子维度 | 拆解问题 |
|--------|----------|
| 题材 | 属于哪一类？有无题材融合创新？ |
| 主角 | 身份起点、核心性格、驱动力是什么？ |
| 金手指 | 外挂形式、解锁条件、代价限制是什么？ |
| 核心冲突 | 主线冲突是什么？个人/势力/理念三层冲突如何交织？ |
| 基调 | 热血/沉郁/轻松/理性/诡异/逍遥？整体情绪色彩是什么？ |

### 2.2 大纲结构

| 子维度 | 拆解问题 |
|--------|----------|
| 卷章布局 | 全书分几个阶段/卷？每个阶段主题是什么？ |
| 起承转合 | 开局如何抓人？中段如何避免疲软？结尾如何收束？ |
| 高潮节点 | 有哪些标志性高潮？节奏间隔如何？ |
| 单元结构 | 副本/案件/地图是否独立成单元？单元间如何串联？ |

### 2.3 世界观

| 子维度 | 拆解问题 |
|--------|----------|
| 地理 | 地图层级如何划分？如何从小地图扩展到大世界？ |
| 力量体系 | 等级如何设计？升级资源是什么？是否稀缺可争夺？ |
| 势力 | 有哪些主要势力？彼此是利益博弈还是理念冲突？ |
| 历史 | 世界历史如何影响当下？有没有古老遗秘？ |
| 规则 | 底层规则是否清晰？有没有既是限制又是破局点的规则枷锁？ |

### 2.4 时间设定

| 子维度 | 拆解问题 |
|--------|----------|
| 时间跨度 | 全书覆盖多长时间？主角成长周期如何？ |
| 锚点事件 | 有没有标志性时间节点（限期之约、纪念日、大典）？ |
| 推进节奏 | 每卷/每章时间推进快慢如何？长跨度如何压缩？ |

### 2.5 人物设计

| 子维度 | 拆解问题 |
|--------|----------|
| 主角 | 人设标签、声音标签（口头禅/自称/习惯动作）、行为模式、成长弧光 |
| 核心配角 | 3～5 个核心配角各有什么标签与信念？有无独立高光？ |
| 反派 | 动机是否立体？是否与主角有理念或利益冲突？ |
| 关系网 | 亲情、友情、爱情、师徒、敌对如何交织？情感锚点是什么？ |

### 2.6 爽点设计

| 子维度 | 拆解问题 |
|--------|----------|
| 爽点类型 | 主要爽点类型及占比（打脸/突破/破案/认知颠覆/悟道/群像等） |
| 分布密度 | 小/中/大爽点如何分布？平均每章几个？ |
| 高潮设计 | 高潮章节有哪些？如何铺垫？是否多爽点叠加？ |
| 情绪曲线 | 压抑→释放的周期如何设计？喘息点在哪里？ |

### 2.7 节奏与钩子

| 子维度 | 拆解问题 |
|--------|----------|
| 张弛周期 | 紧张与松弛如何交替？几章一循环？ |
| 章尾钩子 | 每章结尾通常留什么钩子（悬念/危机/发现/反转）？ |
| 信息推进 | 每章是否都有信息或情绪增量？ |
| 追更感 | 让读者点开下一章的核心驱动是什么？ |

### 2.8 文风与句法

| 子维度 | 拆解问题 |
|--------|----------|
| 句长分布 | 短/中/长句占比及各自使用场景 |
| 标点运用 | 逗号、句号、感叹号、省略号、破折号的使用习惯 |
| 对话 | 对话占比、对话标签、人物声口特征、潜台词密度 |
| 描写 | 五感运用侧重、环境渲染 vs 白描、动作细节、心理外化方式 |
| 高频句式 | 标志性句式与表达模式（只记模式，不抄原句） |

## 三、拆解流程

```
第一步：采样与通读
  → 取开头、中部、结尾三段样本（各 400～600 行），覆盖日常/战斗/对话/心理/设定等场景
  → 清理采集声明、广告、重复章节号

第二步：概要信息
  → 填写概要信息表：题材、体量、核心气质、总评分

第三步：八维逐项拆解
  → 按第二章八张问题清单逐项作答
  → 文风维度另行输出独立的文风档案（见《文风学习指南》）

第四步：提炼与反思
  → 提取 3～5 个可迁移套路（见第六章套路提炼方法）
  → 总结 3～5 条避坑提醒
  → 记录 5～10 个高频句式模式

第五步：横向对比
  → 将本书填入横向对比表（见第五章），确认其在已知作品坐标系中的位置

第六步：入库
  → 输出拆文报告 + 文风档案，存入 .novel/benchmarks/{对标书名}/
```

## 五、横向对比方法

拆解 3 部以上对标书后，用横向对比确认规律与差异。列是书，行是维度。

### 5.1 核心维度总表

| 维度 | 对标书A | 对标书B | 对标书C |
|------|---------|---------|---------|
| 题材类型 | {} | {} | {} |
| 主角起点 | {} | {} | {} |
| 金手指类型 | {} | {} | {} |
| 核心冲突 | {} | {} | {} |
| 基调 | {} | {} | {} |
| 开篇方式 | {} | {} | {} |
| 爽点密度 | {个/章} | {} | {} |
| 节奏快慢 | {} | {} | {} |
| 群像程度 | {高/中/低} | {} | {} |
| 主题深度 | {} | {} | {} |
| 表达效率 | {} | {} | {} |

### 5.2 专项对比表

- **开篇方式对比**：书名 | 开篇核心动作 | 钩子类型 | 适用场景
- **爽点类型对比**：书名 | 第一爽点 | 第二爽点 | 第三爽点 | 特色爽点
- **节奏与钩子对比**：书名 | 张弛周期 | 章尾钩子特点 | 信息推进风格
- **文风特征对比**：书名 | 短句占比 | 感叹号频率 | 对话占比 | 标志性句式模式

### 5.3 对比结论的用法

1. **找共性**：多部成功作品共有的做法（如"每章必有推进"）升级为写作纪律。
2. **找差异**：同一维度上的不同选择（如张弛周期 2～4 章 vs 5～10 章）对应不同基调，用来给自己的作品定位。
3. **找空白**：现有作品没覆盖的组合，即差异化空间。
4. **校验定位**：修稿时对照对比表，检查自己的作品是否偏离了选定的坐标。

## 六、套路提炼方法

### 6.1 提炼步骤

1. 从八维拆解中找出"本书做得最好、且可复用"的设计。
2. 用一句话概括其结构，命名为套路（如"天才陨落开局""限期之约""认知即力量"）。
3. 记录四要素：**结构**（怎么运作）、**效果**（满足什么情绪）、**风险**（常见翻车点）、**适用**（什么题材/阶段可用）。
4. 每部作品提取 3～5 个套路 + 3～5 条避坑提醒，宁精勿滥。

### 6.2 套路卡片模板

```markdown
### {套路名}

- **结构**：{前置铺垫 → 核心动作 → 收束方式}
- **效果**：{情绪满足类型}
- **风险**：{失败模式}
- **适用**：{题材 / 章节阶段 / 节奏位置}
- **变体**：{可替换的要素}
```

## 七、拆文成果应用索引

按创作阶段反向调用拆文成果：

| 创作阶段 | 应查阅的拆解产物 | 用法 |
|----------|------------------|------|
| 核心设定 | 八维之核心设定 + 开局/金手指套路速查 | 用反差、危机或文化锚点建立代入感；外挂要有来历、条件、代价 |
| 世界观 | 八维之世界观 + 结构化记录 | 等级简洁好记；小地图切入逐步解锁；规则既是限制也是破局点 |
| 人物设计 | 八维之人物 + 人物拆解表 | 每人一个标签+一个信念；反派有立场；配角有独立高光 |
| 大纲 | 八维之大纲结构 + 高潮套路速查 | 一卷一主题；用时间节点或标志性事件制造仪式感；伏笔早埋慢收 |
| 细纲 | 章节节拍拆解 + 爽点清单 | 每章有信息或情绪增量；章尾留钩子 |
| 时间线 | 八维之时间设定 | 设置时间锚点；长跨度用闭关/游历/地图切换压缩 |
| 爽点设计 | 爽点清单 + 爽点类型对比 | 按目标读者选密度；大高潮叠加多个爽点 |
